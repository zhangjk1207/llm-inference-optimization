# 缓存和并发调优

前缀 token 命中率不能单独决定首字延迟。应同时记录总输入 token、新 prefill token、命中层级、排队、输出长度和并发。

9 月双节点网关实验中，约 33K token 几乎全命中的前缀、8 token 输出时，16 并发 TTFT P95 约 1.65 秒；另一组约 39.8K 输入、37.6K 命中、仍有约 2.1K 新 token 的请求，3 并发以内满足 P95<2 秒，4 并发约 2.79 秒。这两组输入分布不同，不能用前一组的并发容量代表后一组。

`benchmarks/bench_shared_prefix.py` 用固定共享前缀和独立尾部模拟 chat 网关负载，输出 TTFT、成功率、prompt/cached token 范围。字符重复次数不会自动等于指定 token 命中率；以服务 usage 和缓存指标为准。缺失 cached_tokens 时保持未知，避免将未知误报为零命中。当前脚本每档只跑一轮，P95 仅为该小样本的经验分位数，严谨容量评估应扩大样本、增加多轮并保存请求记录。

## GLM 长输入准入修复（2026-10-10）

实测 backport 中 `max_num_batched_tokens=1152`，物理 Mamba 缓存块也是 1152。解码先调度，MTP k=4 的一个请求通常占用 5 行，剩余 1147；默认长输入块对齐会将它裁为 0，等待队列准入随后停止。`max_num_seqs=16` 是数量上限，不会自动解决 token 预算不足。

部署将 `long_prefill_token_threshold` 设为 1024，使用该版本在阈值小于物理块时支持的私有状态子块 prefill，例如先处理 1024，再处理 128 到达块边界。总预算、物理块、LMCache 传输 chunk 是不同概念；修改 chunk 并不能直接改变物理块。

不能直接把总预算改成 2304：当前 connector 拒绝 Mamba align + MTP + 总预算大于物理块的组合，以防 recurrent state 快照错误，不应删除校验绕过。这里的行为来自实测 backport，不是所有上游版本的通用保证。

模型只有一个 MTP 层；预测 4 个 token 可复用同一层，当前 prefill lookahead 为 1。此前发现的多层 MTP 尾部零推进路径不属于本模型配置。实机验证覆盖 1151/1152/1153/2303/2304/2305 输入 token 的冷、热请求共 12 次。

多数常规 Agent 任务更早完成，但分段会增加冷长输入开销，已在 16K 单请求上测到 TTFT 4.70→6.59 秒。完整实验见 [报告](../results/glm-20261010/README.md)。用户级公平配额与有限等待队列尚未实施。

## DSv4.1 并发扩展

将 max-num-seqs 从 4 扩至 8 时，同步扩展 capture 上限 24→48。第二节点的原报告使用真 token 口径，c8 吞吐 340.7→583.3 tok/s，TTFT 从排队时约 2.3–2.5 秒降至约 0.57–0.73 秒。c1/c4 结果受生产流量影响较大，不能据此证明单路计算效率提升。

第一节点旧版基准曾把 SSE chunk 当 token，投机解码下一个 chunk 携带多个 token，旧数字只能作为 chunk/step 速率。后续报告修正后记录 c1 175、c4 268、c8 385 tok/s；它们来自并发已扩展后的不同场景，不构成严格的 4 路 vs 8 路隔离 A/B。

增加 max-num-seqs 不会增加 KV 总容量。历史约 936K token KV 池能够容纳的满长上下文并发仍有限，应结合目标上下文长度、preemption 和请求队列判断配置。

## LMCache 生命周期

历史 DSv4.1 节点在 vLLM 停止后，LMCache 仍短暂保留 GPU IPC 映射。直接重建 vLLM 时，0.95 显存预算与当前 free memory 冲突，导致启动失败；降预算又因模型权重和 activation/graph 预留使 KV 预算为负。

当时有效的顺序是先停止引擎、确认旧 worker 退出与 IPC 映射释放，再启动引擎。固定等待秒数或固定显存阈值只适用于具体部署，不能保证其他版本具有相同生命周期。生产变更应保留原配置，检查服务健康、缓存命中、错误率和真实长上下文负载。

注册空闲过期是另一种生命周期故障。当前 GLM 同时使用 [ZMQ/IPC 注册存活补丁](../patches/lmcache-registration/README.md)，两项修复应分别验证。

## 规划与已完成工作

本地缓存感知网关、跨节点缓存索引、NVMe 副本和百路扩容材料属于设计/估算。当前草稿没有对应网关实现，也没有将方案图或硬件线性估算作为已实现性能承诺。
